## 1. Scope

The roadmap scope, as it maps onto the code at 527dc8c5:

- **Keyboard (C3).**
  - One IME guard: the React keydown handler and the shortcut registry return on `event.isComposing` or `keyCode === 229` (RA-15, A11Y-05; `react/hooks/use-keyboard.ts:26-28`, `core/keyboard/index.ts:113-125`).
  - `keyboardScope: 'root' | 'combobox'`, default `'root'` (today's behaviour), with a development warning (A11Y-16).
  - `defaultPrevented` honoured on every key, inline Escape inert while closed, Escape in the dialog left to Radix's DismissableLayer (A11Y-14, A11Y-17, RA-38; D136, D141).
  - The palette's keys move from document listeners to React `onKeyDown` on the inline root's div and on `Dialog.Content`, composed with the consumer's handler and guarded to the root's DOM (RA-57, A11Y-16; D136).
  - A pointer press on an item does not take focus from the input (A11Y-15, C5, `item.tsx` owner).
  - Focus returns to the opener when the dialog closes, which restores `apps/docs/guide/accessibility.md:286` ("returns focus to the previously focused element"; the roadmap cites the line as :249 at its writing) (A11Y-02).
  - One display order for the DOM, the virtual positions and `NAVIGATE`, returned by a new core `getDisplayIds(state)` (RA-02, A11Y-03; C4; D133).
- **Announcer v2 (C5).** One persistent `role="status"` container outside the listbox from the first commit; Empty and Loading portal into it with no live role of their own, which restores `react/empty.tsx:3` ("Portals into a container outside the listbox for valid ARIA structure"). Loading polite, the result count debounced (500 ms) and silent while loading: the docs state assertive and an every-change count today, so D138 rules these in D103's form as the fix of A11Y-11, RA-54 and DG-50 (RA-14, RA-X10, A11Y-10 to A11Y-12, DG-50, RA-54).
- **Shortcuts (C2, C5).**
  - Valid `aria-keyshortcuts` (A11Y-18, DT-51, DAE-36, DG-47, DGX-SC-6, RA-53) and a true `Meta` label (CE-12, A11Y-20, DG-68).
  - An `event.code` fallback bounded by the printed character and never run for an AltGraph event (CE-11, A11Y-21; D137). The `+` key, key labels, the macOS glyph order ⌃⌥⇧⌘ (CE-40, CE-42, CE-41; D137).
  - Editable targets skipped behind `shortcutsInEditable: false`: `true` (today) stays the 1.x default and 2.0 flips it (roadmap call). The opt-in `shortcutScope` (A11Y-06; D124).
- **CSS (C6).**
  - The stylesheet is built, not copied, by lightningcss with `targets` at the documented floor (PKG-10, first and mandatory; D58 put it at 1.8.0, D122 rules the build). Tokens move to `:where(:root, :host)` inside `@layer command.base` (A11Y-01, DT-19, RA-10, RA-31). Only the reduced-motion rule is scoped (RA-12).
  - transform-origin and the RTL flip (RC-2, A11Y-33), exit animations (RA-11), `clip-path` (RA-60, A11Y-34), fade edges (RA-52), the forced-colors highlight and the underline cue (A11Y-37; D138), the loading pulse (A11Y-40), a default active indicator (A11Y-25), RA-X8, RA-X9.
  - Smooth scrolling moves from JS to CSS: `list.tsx:120` omits `behavior` (C5) and C6 adds `scroll-behavior: smooth` under `prefers-reduced-motion: no-preference` (A11Y-22; D138).
  - The announcer and the dialog title stop depending on the global `.sr-only` (RA-09, C5).
- **Playground (C7).** The broken demos (PG-01, PG-03, PG-05, PG-06, PG-15, PG-19) and the pass-2 playground rows.
- **E2E (C1, C8).**
  - The foundation first (C1): self-hosted fonts, `reducedMotion: 'reduce'`, a shared fixture that fails on any off-origin request, hard preconditions instead of early returns, an observable selection. Then Firefox and WebKit in the default projects (TEB-81).
  - Then the a11y and visual gate (C8): wcag22aa (SPEC-38, TEB-25, T32), exact matchers (TEB-26, TEB-27, T26, TEB-29), retrying assertions, computed accessible names, axe on every route in both themes (PG-07, A11Y-31), and `toHaveScreenshot` baselines in light, dark, forced-colors and `dir=rtl` (the roadmap's G8, no ledger row), recorded on Linux by the orchestrator (D128).
  - The NVDA smoke is not run in 1.8.0 (D127: owner-gated).
- **Docs and comments (C9),** after the code they describe.

**Out of scope.**
- `ariaNotify` (roadmap "Announcer v2", Opp #7): no installed type declares it. Re-arm: TypeScript's `lib.dom.d.ts` declares it and two engines ship it. No ledger row exists.
- The 2.0 halves of three rows, which change a 1.x default. Each row keeps status OPEN, gains `remaining` and moves to release 2.0.0 at its cluster's ledger commit (D125):
  - A11Y-06: stopPropagation dropped, single-key shortcuts rejected.
  - A11Y-14: Home/End to the caret, PageUp/PageDown.
  - RA-43: `Omit<'id' | 'role'>` on the published prop types.
- Virtual mode with groups (RA-08, 1.9.0). C4 positions and scrolls virtual rows by the display index (D133), so navigation and position agree in both modes; RA-08's group rendering in virtual mode stays 1.9.0's.
- RA-83's end-of-session close, deferred (D129; its first-event half lands in C2; section 3).
- The NVDA smoke and its two devDependencies (D127).
- Rows the roadmap names that are not OPEN 1.8.0 rows (section 3).
