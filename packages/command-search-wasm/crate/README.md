# command-search-wasm (Rust crate)

The Rust source of the experimental trigram fuzzy-search engine behind `modern-cmdk-search-wasm`,
compiled to WebAssembly with `wasm-bindgen`. Licensed MIT; see `LICENSE`.

`pkg/` is generated by `wasm-pack` from this crate and is not committed. Build it from the repository
root:

```bash
pnpm --filter modern-cmdk-search-wasm build:wasm
```

The TypeScript wrapper and usage are documented in the package README one directory up.
